## Featured Project: PhotoStudio Modernization

**Modernizing a legacy photo production management system**

**Project status:** Active development

**Technology stack:** ASP.NET Core, Blazor, C#, SQL Server 2019

### Project Overview

PhotoStudio is a modernization project focused on migrating an existing business application from Visual Basic 6, Delphi, and SQL Server 2000 to a modern web-based architecture.

The primary objective is to preserve established business rules while improving maintainability, database performance, and application architecture.

### Key Engineering Challenges

- Analyzing and preserving business logic from legacy applications.
- Migrating existing data to SQL Server 2019.
- Reimplementing order management and payment workflows.
- Maintaining data consistency and access control.
- Optimizing complex SQL queries and stored procedures.
- Validating new functionality against existing application behavior.

### Engineering Approach

The project emphasizes incremental modernization, controlled database changes, regression testing, and measurable performance improvements.

Database migrations and changes are documented and versioned. Legacy behavior is verified before being changed or replaced.

**Repository:** Private — a public technical case study is planned.
